# 브라우저 전체 흐름 검증

과제6 수동 검증에서는 계획 작성·수정 이력, 할 일 빠른 추가, 타이머 복구·시간 보정, 숫자의 근거 이동, 개선점의 다음 계획 연결, 삭제 실행 취소, 서버 오류 후 입력 보존을 확인했습니다.

과제6 기록은 `docs/baseline/t06/evidence/verification-results.md`에 있습니다. 브라우저는 CUA로 직접 확인했으며 별도 자동 브라우저 테스트 파일은 없습니다. 과제7 관찰 결과와 화면은 docs/evidence/verification-results.md에 기록했습니다.

과제7은 가입·로그인·로그아웃·비밀번호 변경·미로그인 화면 제한·자료 이전 A2·실험 A3~A5·만료 복귀 A6·내보내기와 삭제 A7을 로컬 테스트 DB에서 검증합니다. 입력 자동완성·표시 전환·오류 안내 A1과 모바일·키보드 흐름도 확인합니다. 서버 접근 차단은 HTTP 통합 검증과 함께 확인합니다.

실제 5일 사용은 별도로 사람이 수행하며 브라우저 테스트 자료로 대체하지 않습니다. 공개 운영 DB에서는 검증용 자료를 만들지 않습니다.
