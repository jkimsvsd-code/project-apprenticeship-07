# 실제 5일 실험 규약

상태: A3~A5 구현·계산/순서 검증 완료. 사용자 실제 실험은 시작 전이며 질문·지표·단위·계획 규칙은 본인이 앱에서 정합니다. [실제 사용 절차](five-day-guide.md)를 따릅니다.

## 시작할 때 한 번 정할 값

| 항목 | 현재 값 |
| --- | --- |
| 답하려는 질문 한 문장 | 미정 |
| 관찰 지표 한 개 | 미정 |
| 단위 | 미정 |
| 하루 값과 합계·평균 계산 규칙 | 미정 |
| 값 누락 처리 | 미정. 누락을 자동으로 실제 사용일이나 0으로 만들지 않음 |
| 중복 값 처리 | 미정 |
| 이상값 처리 | 미정 |
| 반올림 위치와 자릿수 | 미정 |
| 주 시작 요일 | 미정 |
| 처음 적용할 계획 규칙 | 미정 |

원본 시각은 UTC로 보존하고 사용일·순서 판단은 Asia/Seoul로 통일합니다. 과제6의 마감일 기준 집계와 과제7 실험의 날짜별 지표를 혼동하지 않도록 근거를 표시합니다.

## 실제 기록 순서

1. 인증·계정별 자료 보호 검증이 끝난 앱에서 설정을 고정하고 1일차를 기록합니다.
2. 다른 실제 서울 날짜에 2일차를 기록합니다.
3. 2일차 뒤·3일차 기록 전에 계획 규칙 하나만 변경합니다. 변경 전후 문장·시각·이유·1/2일차 기록 ID를 보존합니다.
4. 3~5일차를 각각 다른 실제 날짜에 기록합니다. 지표·단위·계산 규칙은 유지합니다.
5. 선택한 실험에는 정확히 5개의 실제 날짜 기록을 포함합니다. 연속 날짜를 원문 요구사항으로 추가하지 않습니다.

기존 과제6 자료는 이전·보존하지만 잠금 적용 뒤의 실제 5일 사용을 대신하지 않습니다. 사용 기록과 규칙 변경 시각을 사후 조작해 순서를 맞추지 않습니다.

## 비교와 검산

변경 전 2일과 후 3일을 구분해 동일 지표·단위·계산 규칙으로 계산합니다. 합계와 평균, 날짜별 원본 근거를 함께 보여 주며 두 기간의 일수가 다름을 표시합니다. 계산 규약에 따라 실제 5일의 화면 수치와 수동 계산을 대조합니다. 변경 후 결과가 나빠져도 그대로 보존하고 이유를 기록합니다.

개인 기록 원본은 비공개 DB와 개인 내보내기에 보관합니다. 제출 증거는 비밀값·개인정보를 검토한 사본을 `docs/evidence/experiment`에 두고 실제 검산식을 연결합니다.
