# UI 방향

목표는 차분하고 깔끔한 다이어리입니다. 많은 장식보다 오늘 할 일, 저장 상태, 계획과 실제의 차이가 잘 보이도록 구성합니다.

## 화면 구성

- 기본 탐색은 **오늘 / 계획 / 돌아보기** 세 영역으로 구성합니다.
- 계획 상세에서 할 일과 수정 이력을 확인합니다. 실행 기록은 해당 할 일에서 열어 연결 관계를 유지합니다.
- 돌아보기는 기간 선택 → 수량·시간 요약 → 근거 목록 → 개선점 → 다음 계획 만들기 순서로 읽힙니다.
- 오늘 화면은 데이터가 없어도 공개 안내와 첫 계획 작성 동작을 제공합니다.
- 집계 화면의 계획 수에는 '할 일 기준'을 함께 표시해 의미를 설명합니다.

## 시각 원칙

| 요소        | 기본안                                            |
| ----------- | ------------------------------------------------- |
| 배경        | 밝은 회색 `#F7F8FA`                               |
| 주요 표면   | 흰색 `#FFFFFF`, 얇은 테두리, 절제된 그림자        |
| 본문        | 짙은 회색 `#1F2937`                               |
| 보조 텍스트 | 회색 `#4B5563`                                    |
| 주요 동작   | 차분한 청록 `#0F766E`                             |
| 배치        | 8px 기반 간격, 넉넉한 내부 여백, 제한된 본문 너비 |
| 서체        | 읽기 쉬운 시스템 한글 서체, 안정적인 줄간격       |
| 상태        | 색과 함께 텍스트·아이콘 사용                      |
| 차트        | 예상·실제 두 계열을 중심으로 수치와 범례 제공     |

텍스트의 대비를 높이고, 초점 표시·모달 초점 이동·모바일에서 닫힌 메뉴의 비활성화를 반영했습니다. 390px와 데스크톱 폭에서 화면을 확인합니다. 차트의 색만으로 차이를 구분하지 않습니다.

## 동작과 피드백

- 화면마다 주요 동작을 명확히 하고 자주 쓰는 동작을 가까이 배치합니다.
- 저장 중 중복 입력을 막고, 서버 확인 후 저장 완료를 표시합니다.
- 저장 실패 시 작성 내용과 오류 이유를 유지하고 재시도할 수 있게 합니다.
- 폼 오류는 해당 입력 옆에 표시하고 첫 오류로 키보드 초점을 이동합니다.
- 삭제 후 실행 취소 동작을 표시합니다. 안내가 사라졌다는 이유로 즉시 물리 삭제하지 않습니다.
- 타이머는 실행 중인 할 일·시작 시각·경과 시간을 함께 보여 줍니다. 타이머 종료와 할 일 완료는 구분합니다.
- 다음 계획 도우미는 복사할 항목과 개선점을 사용자가 확인한 뒤 저장합니다.
- 검색 결과 없음, 첫 사용, 로딩, 통신 실패 상태를 각각 구분합니다.
- 모바일에서는 목록과 핵심 동작을 한 열로 배치하고, 키보드 초점·터치 영역·화면 확대를 확인합니다.

첫 화면의 공개 안내는 처음 방문할 때도 보이는 위치에 유지하고, 나머지 UI와 같은 차분한 정보 배너로 표시합니다.
