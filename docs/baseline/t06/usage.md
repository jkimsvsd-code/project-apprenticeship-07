# 실제 회고와 다음 계획 작성하기

## 회고 한 줄 저장

1. ‘돌아볼 계획’에서 **논문 작성**을 선택합니다. ‘모든 계획’ 상태에서는 회고 입력이 비활성화되어 있습니다.
2. 기간을 확인합니다. 현재 계획의 기본 기간은 **2026-10-24~10-30**입니다.
3. 예상·실제 시간과 막힌 이유를 살펴봅니다. ‘실제 시간’을 누르면 근거 할 일을, ‘주제 탐색’을 누르면 세 실행 기록을 확인할 수 있습니다.
4. **다음에는 어떻게 해볼까요?**의 입력칸에 다음 계획에서 바꿀 행동 한 가지를 적고 **개선점 저장**을 누릅니다.

작성 예시: “탐색 범위를 연구 질문 하나로 좁히고, 다른 일에 밀리지 않도록 매일 30분을 먼저 확보하겠다.” 실제 경험과 본인의 판단에 맞게 고쳐 쓰세요. 예시는 자동 저장되지 않습니다.

## 다음 계획에 연결

1. 같은 화면 아래 **다음으로 이어지는 기록**에서 방금 저장한 회고의 **다음 계획 만들기**를 누릅니다.
2. 열린 창의 **이어갈 개선점**을 확인합니다.
3. 계획 이름·시작일·종료일·우선순위·예상 시간·성공 기준을 입력하거나 수정합니다. 예상 시간의 입력 단위는 **분**입니다. 예를 들어 7시간은 420분입니다.
4. 필요하면 **가져올 할 일**을 선택합니다. 선택한 할 일은 미완료 상태로 새로 생성되고, 마감일은 새 계획의 종료일로 설정됩니다. 과거 실행 기록은 복사되지 않습니다.
5. **다음 계획 만들기**를 눌러 저장합니다.

새 계획 상세의 **지난 돌아보기에서 이어온 한 줄**에 회고가 보이면 연결이 완료된 것입니다. 원래 회고에는 **연결한 계획 보기** 버튼이 표시됩니다. 새로고침 후에도 두 화면의 연결이 유지되는지 확인하세요.

계획 기간은 직접 정할 수 있습니다. 기존 7일 계획에 이어 작성한다면 2026-10-31~11-06 등을 사용할 수 있습니다. 오늘부터 계획을 바꿔 실행하려는 경우에는 실제 실행하려는 기간을 입력하세요.
