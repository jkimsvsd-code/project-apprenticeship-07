## 짧은 확인 방법 4줄

1. 어디로 가나요: [공개 앱의 계획 목록](https://pds-diary-apprenticeship-06-m2021.happybay512.chatgpt.site/?view=plans)을 엽니다.
2. 세 단계 안에 무엇을 하나요: ‘논문 작성’ 카드 누르기 → ‘이 계획의 예상과 실제를 돌아볼까요?’ 누르기 → ‘실제 시간’ 숫자 누르기.
3. 무엇이 보이면 통과인가요: 할 일 5개와 실제 시간 75분의 근거가 보이며, ‘주제 탐색’을 열면 35·20·20분 기록의 시각과 막힌 이유를 확인할 수 있습니다. 저장한 값은 새로고침 후에도 유지됩니다.
4. 안 될 때는 무엇이 보이나요: 연결·저장 오류와 다시 시도 안내가 보입니다. 저장 실패 시 입력 내용은 유지되며, 입력 오류는 폼에 표시됩니다.

## AI와 내 판단 3줄

1. AI에게 맡긴 일: 과제 요구사항 정리, 폴더 구성, 앱 UI·서버 DB·집계·테스트 구현과 문서 정리.
2. 내가 직접 판단한 일: 필수 기능과 A·B 전체 및 깔끔한 UI 방향을 승인하고, 논문 작성 계획과 실제 실행 자료를 제공했으며, 기록의 시각·시간·연결 및 앱·소스의 공개 범위를 결정함. AI가 제안한 회고 문장을 실제 회고로 채택하고 10월 31일~11월 6일의 ‘논문 작성 2차’ 계획 생성을 승인함.
3. AI 제안을 따르지 않은 일: 첫 기록의 소요 시간을 25분으로 보존하는 안 대신 오전 07:30~08:05의 시각 차이에 맞춘 35분으로 보존하도록 정정함.

## 실제 회고와 다음 계획 연결

사용자 승인에 따라 다음 문장을 ‘논문 작성’의 실제 회고 개선점으로 저장했습니다.

> 탐색 범위를 연구 질문 하나로 좁히고, 다른 일에 밀리지 않도록 매일 30분을 먼저 확보하겠다.

[저장된 실제 회고 열기](https://pds-diary-apprenticeship-06-m2021.happybay512.chatgpt.site/?view=review&plan=ca91d37f-d130-4e1c-9921-d485ca8c9b71)에서 연결된 [‘논문 작성 2차’ 계획](https://pds-diary-apprenticeship-06-m2021.happybay512.chatgpt.site/?view=plans&plan=b918f193-8a6a-4332-92fe-06587dafc66f)을 확인할 수 있습니다.

| 항목 | 내용 |
| --- | --- |
| 다음 계획 | 논문 작성 2차 |
| 기간 | 2026-10-31~11-06, 7일 |
| 성공 기준 | 구조와 논리를 충족한 논문 초안 작성 완료 |
| 예상 시간 | 총 28시간 |
| 연결 확인 | 기존 회고에 다음 계획이 연결되어 있고, 새 계획에 이전 회고 문장이 표시됨 |

회고 문장은 AI의 제안을 사용자가 실제 회고로 채택한 내용입니다. 2차 계획에는 할 일과 과거 실행 기록을 복사하지 않았으며, 기존 할 일 5개와 실행 기록 3개·75분은 보존했습니다. 공개 DB의 실제 자료는 계획 2개·할 일 5개·실행 기록 3개·회고 1개입니다. 실제 사례의 Plan → Do → See → 다음 Plan 연결을 완료했습니다.
