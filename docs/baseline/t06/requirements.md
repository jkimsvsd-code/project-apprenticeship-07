# 승인 범위와 구현 단계

승인일: 2026-10-27 (Asia/Seoul)

사용자는 과제6의 필수 기능과 UX 개선 A·B 항목 전체, 깔끔한 UI 방향을 승인했습니다. 이 문서는 구현 범위를 나타내며 기능 구현 완료를 뜻하지 않습니다.

## 기본 목표

본인의 실제 계획 → 할 일 → 실행 기록 → 근거가 있는 돌아보기 → 다음 계획의 개선이 이어져야 합니다. 계획 기준을 보존하고, 정확한 숫자를 산출하며, 실제 서버 DB에 저장한 기록을 다시 불러올 수 있어야 합니다.

## 집계 규칙

모든 집계와 근거 목록은 같은 대상 집합을 사용합니다.

| 항목      | 기준                                                                 |
| --------- | -------------------------------------------------------------------- |
| 계획 수   | 해당 계획에 연결된 삭제되지 않은 할 일 수. 계획 문서 개수가 아님     |
| 완료 수   | 대상 중 현재 완료 상태인 할 일 수                                    |
| 지연 수   | 미완료이며 마감일이 서울 시간 기준 오늘보다 이전인 할 일 수          |
| 막힘 수   | 막힌 이유가 하나 이상 있는 할 일 수. 같은 할 일을 중복 집계하지 않음 |
| 예상 시간 | 대상 할 일의 예상 시간 합계                                          |
| 실제 시간 | 대상 할 일에 연결된 실행 기록의 실제 소요 시간 합계                  |
| 시간 차이 | 실제 시간 − 예상 시간. 대상이 없으면 각각 0                          |

오늘이 마감인 할 일과 완료한 할 일은 지연 수에 포함하지 않습니다. 완료 취소 후에는 현재 상태에 맞게 완료·지연 수를 다시 계산합니다.

## 승인된 UX 개선 A

- 오늘 할 일 화면: 오늘 마감·지연·진행 중을 구분합니다.
- 빠른 추가: 같은 계획에 연속 입력할 때 계획·우선순위·태그를 유지하고, 제목·실행 시각·막힌 이유는 복사하지 않습니다.
- 저장 상태: 저장 중·완료·실패를 표시하고 실패한 입력은 보존해 재시도할 수 있게 합니다.
- 삭제 실행 취소: 삭제 직후 복원 동작을 제공합니다.
- 입력 검증: 기간·시각·소요 시간의 오류를 입력 위치에서 안내합니다.
- 모바일·키보드 대응: 주요 동작을 작은 화면과 키보드로 수행할 수 있게 합니다.

## 승인된 UX 개선 B

- 실행 타이머: 시작·종료 입력을 돕고 수동 시각·시간 수정을 허용합니다.
- 계획 변경 비교: 변경 전후 값과 최초 기준을 확인합니다.
- 조회 조건 유지: 기간·검색·필터·정렬을 화면 주소에 반영하고 뒤로 가기에도 유지합니다. 공개 URL에 민감한 검색어가 남을 수 있음을 고려해 공유 시 조건을 확인할 수 있게 합니다.
- 시간 비교 차트: 예상·실제·차이를 표시하고 동일 수치를 표나 텍스트로도 제공합니다.
- 다음 계획 도우미: 개선점과 선택한 계획 항목을 복사하되 완료 상태·과거 실행 기록은 복사하지 않습니다.
