## 공개 범위

사용자가 소스 전송과 로그인 첫 화면 공개 배포를 명시 승인했습니다. Sites의 외부 진입을 공개하고, 앱은 자기 계정의 가입·로그인으로 자료를 보호합니다. 로그인/가입 화면과 정적 UI 자산은 익명으로 열 수 있지만 개인 자료·실험·내보내기 API는 인증 없이 401입니다. 타 계정 자료의 읽기·수정·삭제는 404로 거절합니다.

소스는 본인의 Sites 관리 원격 소스 저장소로 전송했습니다. 이것이 GitHub public 저장소 생성이나 공개를 뜻하지 않습니다. GitHub URL은 별도로 연결해야 합니다.

## 제외한 자료

- `.local`의 개인 백업·전체 테스트 해시·임시 QA 인증 파일.
- `.dev.vars`, 실제 환경변수·키·쿠키·토큰·비밀번호.
- 로컬 DB·덤프·원시 네트워크 캡처·의존성·런타임 상태.

전송 목록과 배포 아카이브를 검사했습니다. 공개 증거에는 인증값을 마스킹하고 전체 저장 해시를 넣지 않았습니다. 과제6의 조상 이력은 유지했습니다.
