# 직접 진행할 실제 5일 사용 절차

이 문서는 사용자 본인의 실제 사용을 위한 안내입니다. 자동 테스트의 가상 날짜와 테스트 계정은 제출용 실제 사용으로 세지 않습니다. 기존 과제6의 과거 기록도 잠긴 앱을 사용한 5일 기록을 대신하지 않습니다.

2026-10-27 확인: 본인 계정 가입·과제6 자료 이전·실험 설정 저장은 완료됐습니다. 실제 일별 기록은 0/5일, 규칙 변경은 0/1회입니다. 기존 자료를 다시 가져오거나 새 실험을 만들 필요 없이 현재 실험의 오늘 값을 실제 수행 후 기록하는 것이 다음 단계입니다. 질문·지표·단위·규칙은 본인 계정에서 확인하며 공개 문서에 옮기지 않습니다.

## 시작 전: 본인 계정과 기존 자료

1. 과제7 앱을 열고 본인이 이메일과 비밀번호로 계정을 만듭니다. 비밀번호는 AI·README·제출 문서에 적지 않습니다.
2. 왼쪽 ‘기록 이어오기’에서 과제6의 전체 내보내기 JSON을 선택합니다. 이 PC에는 `.local/t06-backup.json`으로 원본을 보존했습니다. 이 파일은 Git에서 제외됩니다.
   macOS에서 숨김 폴더가 보이지 않으면 파일 선택창에서 Command+Shift+G를 눌러 프로젝트의 `.local` 폴더 경로로 이동한 뒤 `t06-backup.json`을 선택합니다.
3. 대상 계정이 본인인지 확인하고 계획 2개·수정 이력 2개·할 일 5개·실행 3개·회고 1개, 실행 합계 75분을 확인합니다. 타이머·완료 기록은 백업 시점에 0건입니다.
4. ‘확인한 자료를 내 계정으로 가져오기’를 누릅니다. ‘나의 계획’과 ‘돌아보기’에서 내용·시간·회고와 다음 계획 연결을 확인합니다. 동일 자료를 다시 선택하면 이미 가져온 자료로 안내합니다.
5. 과제6 공개본은 그대로 남습니다. 과제7의 새 비공개 기록은 과제7에 입력합니다.

## 1일차: 질문과 계산 기준을 고정하고 실제 값 기록

‘5일 실험’을 열고 다음을 정합니다.

- 답하려는 질문 한 문장.
- 관찰할 지표 한 개와 단위.
- 처음 적용할 계획 규칙 하나.
- 합계·평균 표시 반올림 0~3자리와 주 시작 요일.

질문 예시는 ‘시작 시간을 정하면 논문 작성에 집중하는 시간이 늘까?’, 지표 예시는 ‘하루 논문 집중 시간’, 단위 예시는 ‘분’입니다. 예시를 실제로 수행했다고 간주하지 말고 본인이 실행할 기준을 선택합니다.

시작 전에 고정할 계산 규칙도 확인합니다. 하루의 실제 값을 직접 입력하고, 합계는 원값의 합, 평균은 합계 ÷ 실제 기록일 수입니다. 표시 마지막에만 반올림합니다. 누락 날짜는 0이나 사용일로 만들지 않습니다. 같은 서울 날짜에는 한 건만 기록합니다. 0~1,000,000 범위의 이상값도 원값과 메모를 보존하고 범위 밖 값은 거절합니다.

‘설정을 확인하고 실험 시작’을 누른 뒤 오늘 실제 수행한 값을 기록합니다. 실제로 하지 않았다면 지표 정의에 맞는 0과 근거를 기록할 수 있지만, 하지 않은 일을 했다고 작성하지 않습니다. 날짜와 작성 시각은 서버가 정합니다. 확정한 기록은 수정하지 않으므로 값을 확인하고 저장합니다.

## 2일차: 기록 후 계획 규칙 하나 변경

다른 실제 서울 날짜에 2일차를 기록합니다. 첫 두 기록을 읽고 앱에 표시되는 ‘계획 규칙 하나만 바꿔 보세요’를 작성합니다.

1. 질문·지표·단위·계산 규칙은 유지합니다.
2. 시작 시각·실행 분량 등 계획의 조건 중 한 가지를 바꾸는 문장을 적습니다.
3. 1일차와 2일차를 근거로 이유를 적고 저장합니다.

앱은 이전/새 규칙·이유·서버 시각·1/2일차 ID를 연결해 보존합니다. 이 변경은 정확히 한 번만 가능합니다. 3일차 기록은 변경이 끝나기 전에는 저장할 수 없습니다. 한 문장에 여러 조건을 동시에 바꾸지 않는지는 본인이 확인해야 합니다.

## 3~5일차: 새 규칙으로 기록

각각 다른 실제 서울 날짜에 새 계획 규칙으로 행동하고 같은 지표·단위로 기록합니다. 같은 날짜 중복 기록·과거 날짜 지정·실험의 6번째 기록은 허용하지 않습니다. 기록을 놓친 날을 꾸며 채우지 말고 다음 실제 날짜에 이어갑니다. 원문은 연속 날짜 5일을 요구하지 않으므로 서로 다른 실제 날짜 정확히 5개를 채우면 됩니다.

‘변경 전’은 첫 2일, ‘변경 후’는 뒤 3일입니다. 두 기간의 일수가 다르므로 합계와 함께 평균·날짜별 근거를 확인합니다. 결과가 나빠져도 값을 바꾸지 않고 이유를 기록합니다.

## 5일차 완료 후: 검산과 제출

1. 5개의 원래 값을 직접 더해 화면 합계와 비교합니다. 평균은 그 합계 ÷ 5로 계산하고 처음 정한 자리에서 반올림합니다.
2. 앞 2일의 합계/평균과 뒤 3일의 합계/평균도 같은 방법으로 확인합니다.
3. ‘계정과 자료’에서 범위를 확인하고 전체 파일을 내려받습니다. 다운로드 목록에서 저장 완료를 확인합니다.
4. 개인 원본 파일은 비공개로 보관합니다. 제출용 사본에서 비밀번호·토큰·세션·비밀키·개인정보를 제거하고 실제 기록·규칙 변경·검산 근거를 정리합니다.
5. [실제 사용·검산 양식](evidence/experiment/manual-check.md)의 사본에 실제 값과 직접 계산한 식을 채웁니다. 공개 전 검토한 제출용 사본만 `docs/submission.md`에 연결하고 남은 두 체크 항목을 갱신합니다. 계정 삭제 기능은 이미 폐기용 계정으로 검증했으므로 제출을 위해 본인 주 계정을 지울 필요는 없습니다.

## 일정을 정하는 방법

오늘을 1일차로 시작한다면 서울 기준 오늘 값을 실제로 기록한 뒤 다음 실제 날짜를 2일차로 사용합니다. 시작 전 과거 날짜를 미리 채우거나 자동으로 5일을 완료 처리하지 않습니다. 이 안내는 일정이나 알림 자동화를 생성하지 않습니다.
