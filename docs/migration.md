# 기존 자료를 계정으로 이전하기

상태: A2 구현·로컬 통합/브라우저 검증 완료. 과제6 실제 자료는 원본 미변경 상태로 비공개 로컬 백업에 보존했습니다. 본인 계정 생성 후 앱에서 실제 이전을 실행합니다.

## 순서

1. 과제6 최종 제출 커밋과 이전할 원본 데이터의 기준 시점을 확인합니다.
2. 본인이 확인한 대상 계정을 지정합니다. 첫 가입자에게 기존 자료를 자동 귀속시키지 않습니다.
3. 원본은 Git 제외 위치에 백업하고 계획·할 일·실행·타이머·완료·회고·수정 이력·중복 요청 처리 자료를 조사합니다.
4. 대상과 건수, 연결 관계, 시간 합계를 미리 보여 줍니다. 원본의 비밀값이나 타 계정 자료는 화면에 노출하지 않습니다.
5. 일회성 이전을 수행하고 같은 원본을 재시도해도 중복 생성·잘못된 재귀속이 없게 합니다.
6. 이전 후 건수·ID 관계·실행 시간 합계·회고/다음 계획 연결·소유자 없는 자료 여부를 대조합니다.
7. 다른 계정이 이전된 자료를 읽거나 수정·삭제·목록 조회·내보내기 할 수 없는지 검증합니다.

## 구현할 보장

- 자료의 소유자는 서버에서 확인한 지정 계정으로 고정합니다.
- 이전 전후 수량·합계와 실패 시 복구/재시도 결과를 기록합니다.
- 이전 ID와 완료 상태를 서버에서 관리해 중복 이전을 방지합니다.
- 실제 원본 데이터와 계정 매핑은 공개 저장소에 포함하지 않습니다.
- 이전 기록은 과제7의 잠긴 앱에서 새로 수행할 실제 5일 기록과 구분합니다.

소스 위치: `src/features/migration`, `src/server/migration`, `app/api/import`. 검증 위치: `tests/integration/migration`. POST /api/import의 preview/import를 구현했습니다. 원본 내용은 허용한 필드만 읽고 계정별로 ID를 다시 매핑하며 이전 관계와 시각을 보존합니다.
