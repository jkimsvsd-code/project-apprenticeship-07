# 과제7 검증 결과

검증일: 2026-10-27 (Asia/Seoul). 로컬 Cloudflare Worker·D1와 별도의 폐기용 테스트 계정으로 검증했습니다. 실제 사용자 계정의 비밀번호를 만들거나 실제 5일 사용 기록을 작성하지 않았습니다.

## 실행 검사

| 검사 | 관찰 결과 |

| Git 기준 커밋 | 과제6 `53ee04f3d3865e89fde664f56bca93d614057560`이 조상에 포함됨 |

실제 요청과 응답은 [http-results.json](authentication/http-results.json)에 있습니다. `cookie-ref-N REDACTED`는 실행 중 같은 원문 쿠키에 붙인 비공개 별칭으로, 원문을 공개하지 않고 로그아웃 전후 같은 값을 재사용했음을 대조합니다. 원문 쿠키와 비밀번호는 기록하지 않았습니다. 저장 해시는 종료 시 삭제한 폐기용 계정의 값입니다.

## 확인한 서버 경계

- 로그인 화면 200, 미로그인 자료 화면 307 로그인 이동, 직접 API는 401.
- 정상 가입·로그인·중복 가입 거절, 없는 계정과 틀린 비밀번호의 상태/문구 동일.
- 같은 임시 비밀번호의 서로 다른 scrypt 저장값, 비밀번호 원문 비노출, HttpOnly 쿠키.
- 본인 읽기·수정·삭제·복원 성공, A→B/B→A 읽기·수정·삭제 모두 404.
- 거절 전후 상대 자료 내용·건수 동일. 다른 계정의 부모 계획·타이머 대상 ID도 거절.
- URL·헤더·본문의 소유자 위조를 무시하고 본인 자료만 반환/생성. 익명 위조는 401.
- 목록·관련 자료·내보내기 분리, 교차 출처 쓰기 403, 계정별 중복 요청 ID 분리.
- 같은 GET·같은 기존 쿠키로 로그아웃 전 200, 뒤 401. 비밀번호 변경 전 쿠키도 401, 새 쿠키는 200.
- DB 만료 시각을 지난 테스트 세션은 401.
- 틀린 비밀번호의 계정 삭제 거절, 올바른 삭제 뒤 계정·자료·세션 제거, 다른 계정 자료 그대로 유지.
- 이전 자료의 관계·내용·시각·합계 보존, 같은 파일/내보내기 시각 변경에도 중복 없음, 잘못된 파일과 DB 제약 실패 시 전체 되돌림.
- 5개의 서로 다른 서울 날짜, 2일차 뒤/3일차 전 규칙 변경 1회, 참조 ID 보존, 중복 날짜·순서 위반·6번째 기록 거절.
- 원값 합계 후 마지막 반올림, 앞 2일/뒤 3일 각각 다른 분모로 같은 기준 계산.

## 남은 실제 작업과 한계

- 본인 계정 가입과 실제 자료 가져오기, 실제 날짜 5일 사용, 규칙 변경, 실제 값 수동 검산은 사용자 작업입니다. [절차](../five-day-guide.md)
- 자동 테스트는 가상 날짜를 함수 인자로 주입했으며 브라우저/공개 API에는 날짜를 바꾸는 기능이 없습니다.
- 원격 Sites 소스 전송은 자동 승인 검토에서 목적지 미승인·증거의 해시 포함을 이유로 거절되어 중단했습니다. 공개 해시는 마스킹하고 전체 값은 로컬 Git 제외 파일로 분리했습니다. 외부 배포·공개 접근 검증은 승인 뒤 진행해야 합니다.
- 새 GitHub public 저장소 URL과 실제 과제6 최종 제출 커밋과의 일치 대조는 최종 제출 시 확인해야 합니다. 이 작업에서는 GitHub Actions의 원격 실행 결과를 주장하지 않습니다.
- 인증/소유권을 로컬 실제 Worker에서 검증했으며 별도의 외부 보안 감사나 부하·다중 리전·모든 브라우저/기기 검증은 수행하지 않았습니다. 반응형 스타일을 구현했지만 모바일 실제 기기 결과로 표시하지 않습니다.
- 이메일 확인·비밀번호 찾기·MFA·분산 무차별 대입 방어와 계정 복구는 제공하지 않습니다. 자세한 위험은 [설명서 ⑥](../authentication.md)에 있습니다.

공개 증거의 저장 해시는 일부만 표시합니다. 실제로 비교한 폐기용 계정의 전체 해시는 Git 제외 파일 `.local/qa-password-hashes.json`에만 보관하며 원문 비밀번호는 보관하지 않습니다.
