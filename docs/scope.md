# 승인 범위

승인일: 2026-10-27 (Asia/Seoul).

사용자 승인: “필수 단계 전체와 UX A1~A7 모두 승인해. 이 범위를 기준으로 GitHub public 공유에 적합한 폴더 구조를 구성하고 트리로 보여줘.”

후속 지시에 따라 필수 단계 전체와 UX A1~A7을 구현하고 로컬 검증을 완료했습니다. 실제 계정 가입·기존 자료 가져오기와 실제 5일 사용은 본인이 진행합니다. 현재 상태는 roadmap.md, 실제 결과는 evidence/verification-results.md를 참고합니다.

| 단계 | 범위 |

## UX A1~A7

| 항목 | 승인한 기능 | 책임 위치 |
| --- | --- | --- |
| A1 | 비밀번호 표시 전환·자동완성·인증 입력 오류 안내 | `src/features/auth` |
| A2 | 자료 이전 대상·건수 미리보기·완료 확인·중복 이전 방지 | `src/features/migration`, `src/server/migration` |
| A3 | 질문·지표·단위·계산 규칙의 실험 시작 도우미·진행 현황 | `src/features/experiment` |
| A4 | 2일차 뒤 규칙 변경 안내·변경 전후·이유 기록 | `src/features/experiment`, `src/server/experiment` |
| A5 | 변경 전 2일과 후 3일의 합계·평균·일별 근거 비교 | `src/features/experiment`, `src/shared/experiment` |
| A6 | 세션 만료 후 원래 화면·같은 계정의 미저장 입력 복귀 | `src/features/auth`, `src/server/auth` |
| A7 | 내보내기 범위·성공 여부·계정 삭제 범위와 복구 안내 | `src/features/account`, `src/server/accounts` |

검색·필터·타이머·모바일·일반 저장 오류 처리 등 기존 과제6 UX는 계승합니다. A6의 입력 복구에는 비밀번호를 포함하지 않고, 로그아웃이나 계정 전환 시 다른 계정에 입력이 나타나지 않게 합니다.

## 제외한 선택 기능

B1 비밀번호 찾기·이메일 재설정, B2 기기별 세션 목록·전체 로그아웃 UI, B3 기록 알림, B4 제출 증거 자동 정리 도구는 승인 범위에 포함하지 않습니다. 필수 비밀번호 변경과 이전 인증값 폐기는 B1·B2와 별개로 구현 대상입니다.

인증은 Better Auth 1.7.14와 DB 세션입니다. 실제 실험 질문·지표·규칙은 본인이 정합니다. GitHub public 저장소 연결과 라이선스는 미확정입니다.
